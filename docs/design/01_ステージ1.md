## まちがえたとき

- 判定は「不正解。」とはっきり出し、次にすることを1つ添える（必ず守るルール1）。
- 天王寺で反対の電車 → 「券売機の前から やり直しましょう。」→ 改札の場面から（定期券はもう持っているので買い直さない）。
- 本町で反対の電車 → ホームの場面からやり直し。
- 電話に出る → まわりの人がこちらを向く（！が出る）→ 不正解 → もう一度えらぶ。
- 点数は減らさない。ブザーは使わない。

## 台本を直すとき

- 文は `content/stages/stage1.json` を直す。1こまのセリフは1文・30字まで・分かち書き。
- 新しい漢字を使ったら `npm run lint:content` が止める。`npm run furigana:suggest` で読みの候補を出し、1つずつ見てから `content/furigana.json` に足す。
- 看板・電光掲示板の中身は `content/places.json`、路線図は `content/metro.json`、NMChat は `content/nmchat.json`、豆知識は `content/tips.json`。
- 場面（3D）の id・合図の名前は、`src/stages/stage1/` のプログラムと合わせる（台本の `wait` の event・`target`・`fx`）。
- 直したら `npm run e2e` で最後まで通るかを確かめる。
