## 章と場面

章は2つ（tomy さん 2026-11-22「第二章は会社ついてから」）。
**第1章「家から 会社の 駅まで」** が下の表の全部（目覚まし〜阿波座に着く）。
**第2章「会社に 着いてから（入社式）」** は企画メモの「#入社式」の順（受付 → エレベーター → 入社式の席）に、
tomy さんの指示（2026-11-23）の「会場に着いたら、ヘンディさんにマイクで『おはようございます』。ここから Gemini Live の会話。
自己紹介のような N5 の質問に マイクで答える → 席に座る → ヘンディさんのあいさつ → 今後のことは ○○先生から」を入れた（下の表の s14・s15）。
修了証は、ステージの終わり（第2章の終わり）に移した。

第2章で決めたこと（理由）:

- 受付の人・会場の新人は、名前の無い人にした。ヘンディさんは実在の社員がモデルなので、まちがえる役はさせない（必ず守るルール8）。
  企画メモの「後ろに座ると、前の方に来て〜と言われる」は、ヘンディさんが学生に言う（ヘンディさんの失敗ではない）。
- 会場の階は 7階（会社が実際に 7階にある。`docs/research/` の住所）。受付の人が教え、メモに残る。
- エレベーターのボタンは B1・1〜7（「G」が無い）。1階が地面の階、という豆知識を出す（企画メモ「カンボジアと違ってGがないことに気づく」）。
- 声の練習は選択式にしない（必ず守るルール3）。決まったセリフ（受付のあいさつ・おはようございます）は、聞きとった文に
  大事なことば（本日・入社・申します など）が入っていれば合格。足りないときは、何が大事かを1つ伝えて もう一度。
  質問の答えは、日本語で答えていれば次へ進む。中身が合わないときは、ヘンディさん（AI）が正しい言い方の見本を返事で言う。
- 質問は台本（`content/talks.json`）に書いた5つ（名前・出身・大学で勉強したこと・趣味・好きな日本の食べ物）。
  AI に「この文をそのまま言って」と頼み、画面には台本の文を出す（ふりがなが付く）。
- 「今後のことについては ○○先生から」の ○○ は、管理者の画面で変えられる（いまは 冨永先生）。
- 会場の席には、同じ学校・期生の登録メンバー（academy と共有のユーザーの表）が、後ろの列から座る。頭の上に呼び名を出す。
  前の列は両はし以外あけておく（前の席の豆知識のため）。いすはキャスターの無い、黒いクッションのいす（tomy さん 2026-11-23）。

AI の返事と、学生の声を聞きとった文は、その場でできる文なので、読み方のデータに無い漢字が出ることがある（ふりがなが付かない）。
台本の文（質問・しめくくり）は、いつもふりがなが付く。

## まちがえたとき

- 判定は「不正解。」とはっきり出し、次にすることを1つ添える（必ず守るルール1）。
- 天王寺で反対の電車 → 「券売機の前から やり直しましょう。」→ 改札の場面から（定期券はもう持っているので買い直さない）。
- 本町で反対の電車 → ホームの場面からやり直し。
- 電話に出る → まわりの人がこちらを向く（！が出る）→ 不正解 → もう一度えらぶ。
- 点数は減らさない。ブザーは使わない。

## 台本を直すとき

- 文は `content/stages/stage1.json` を直す。1こまのセリフは1文・30字まで・分かち書き。
- 新しい漢字を使ったら `npm run lint:content` が止める。`npm run furigana:suggest` で読みの候補を出し、1つずつ見てから `content/furigana.json` に足す。
- 看板・電光掲示板の中身は `content/places.json`、路線図は `content/metro.json`、NMChat は `content/nmchat.json`、豆知識は `content/tips.json`。
- 場面（3D）の id・合図の名前は、`src/stages/stage1/` のプログラムと合わせる（台本の `wait` の event・`target`・`fx`）。
- 直したら `npm run e2e` で最後まで通るかを確かめる。
