# リスニング（聞こえた言葉を入れると、かくれたセリフが浮かび上がる）

tomy さんの指示（2026-11-24）:

> ヘンディさんから入社式の最初のお話があります。当たり障りのない形で作って。テーマは『海外の学生が日本のITの会社で働くために大切なこと。』
> 話す前に聞こえた言葉をメモするように伝えて。メモしている絵を表示させて。
> これは ネクマックスアカデミーの時に、使っていたリスニングの問題と同じ内容を、3D の、画面で表現するようにしてください。
> 読み上げられている言葉を、入力すると、セリフが浮かび上がるような形で、お願いします。
> 文章とゲームレイアウトはふぇいぶるが考えて、実装はOpus。デザインは、今作られている動物の森風の柔らかいデザインにしてください。セリフは虫食い状態。
> もじが浮かび上がったとして、文章の意味を理解するためのワークも入れたいので、自然に楽しく学習できるアイデアを考えて。

この文書は、文とレイアウトの設計（Fable）。実装は Opus が行う。
リスニングの部品は、ステージ2（お客さまとのミーティング。`docs/design/03_ステージ2.md`）でも同じものを使う。

## 1. 遊び方（academy のリスニングと同じ）

academy の「聞こえた ことばを 入れてみよう」（`nexmax-academy` の `src/components/listening/playback-mode.tsx`・`listening-panel.tsx`・`listening-checks.ts`）と同じ遊び方にする。

- 台本（セリフ）は、はじめは かくれている。かくれた字は1字ずつ箱（□）で出る。句読点・かぎかっこ・空白は はじめから見える（長さと区切りが分かる）。
- 声を聞いて、聞こえた言葉を入れる（ひらがなでも漢字でもよい）。台本の中にあれば、その言葉が**全部の場所で**開く。
  読みの途中が当たったら、その言葉（漢字の かたまり）が丸ごと開く。
- 点: キーワードを台本どおり（漢字）= 5点、キーワードを読みで = 3点、台本にある ほかの言葉 = 2点、長い言葉ほど おまけ。
  おなじ言葉は「もう 見つけたよ」（0点・ミスにしない）。ローマ字は「日本語で 打って みて ください」。
- 開いた割合が `revealGoal`（%）になったら「こたえあわせ」に進める。全部は開けなくてよい（「ぜんぶ 分からなくて だいじょうぶです」）。
- こたえあわせ: 1文ずつ、全部 開いた文と ふりがなを見ながら、もう一度聞く。

**判定のプログラムは academy から移す**（同じ持ち主の姉妹アプリ。`src/components/listening/listening-checks.ts` と、数字・英字の読み `src/content/listening-sounds.ts` の要る所、そのテスト）。
置き場所は `src/lib/listening/`。読みは、このアプリの読み方のデータ（`content/furigana.json` の索引）を使う。

### 「虫食い」にする（academy と ちがう所）

N5 の人が、何も無い所から始めると むずかしい。台本に `preOpen`（はじめから開けておく言葉）を持たせ、始めるときに 点なしで開ける。
文の終わり（です・ます・ください など）が見えて、中身の言葉が かくれた「虫食い」になる（例:「1つ目は、□□□□です。」）。

### 行きづまらない

- 「ヒント」: 1回 全部聞いたあと、または ミスが `maxMiss` 回になったら押せる。まだ開いていないキーワードを1つ選び、
  1回目は「はじめの1字と 字の数」（例:「そ□□□（4文字）」）、同じ言葉で もう1回押すと 読みを全部 出す（自分で打って開ける）。点は へらさない。
- 文を押すと、その文だけ もう一度 聞ける。速さは「ゆっくり 0.7・すこし ゆっくり 0.85（はじめ）・ふつう 1」（声の高さは変えない）。
- 貼り付けは できない（academy と同じ）。

## 2. 声（ヘンディさんが読む）

- 声は Gemini Live で、**使う人のキー**で、その場で作る（共有のキーは置かない。必ず守るルール4）。1文ずつ作り、作った音は覚えておいて（同じ画面の間）、聞き直しは同じ音を使う。
  academy の `src/lib/audio/live-tts.ts`（書いてあるとおりに読ませる指示。質問の形でも答えない）と `wav.ts` を移す。
  接続キーの作り方は、今の `src/lib/ai/live.ts` のもの（短い時間だけ使える接続キー）を共通にして使う。マイクは使わない（マイクの許可を聞かない）。
- 再生している文の次の文を、先に作っておく（待ち時間を作らない）。はじめの1文だけ「じゅんび中…」が出る。
- 読みまちがい（文を言いかえる・答えてしまう）を防ぐ: 返ってきた文字起こしを台本の読みと比べ、大きく ちがうときは 1回だけ作り直す。
- 声は人ごと（ヘンディさん = `Puck`。academy と同じ）。台本の `participants[].voice`。
- うまく作れないとき: 理由と「設定を 開く」「もう 一度」「ブラウザの 声で 聞く」（日本語の声があるときだけ）「ステージを 出る」を出す。
- 自動テスト: `window.__fakeLive` があるときは 声を作らず、1文を みじかい時間で「再生した」ことにする。

先々: academy のように、先に作った音声ファイル（`public/audio/listening/<id>/NN.wav`）を置けば、キーが無くても聞ける。今回は作らない（キーが要るため）。

## 3. 画面のレイアウト（1280×720 が基準。どう森ふうのクリームのカード）

リスニングの間、3D は「前の台のヘンディさんと、うしろの大きな画面」が**上の 55%** に見える向き（新しいアップの向き `speech`）。
画面の下に、クリームのカード（`.glass`・角は大きく丸く）を2つ ならべる。左上の「いま すること」と右上のメニューは そのまま。右上のメモの箱は、リスニングの間は かくす。

```
┌────────────────────────────────────────────────────────────────────────┐
│ いま すること: 聞こえた 言葉を 入れよう                        [メニュー] │
│                                                                        │
│            ┌──────── 3D の 大きな 画面 ────────┐                        │
│            │   2つ目は、 □□ です。           │   ← いま 読んでいる 文  │
│            └──────────────────────────────────┘      （虫食い・大きい字） │
│                      ヘンディさん（話している）                          │
│                                                                        │
│ ┌─ メモ（入れる所）────────────┐ ┌─ ノート（台本）──────────────────┐ │
│ │ 🎧 ヘンディさんの お話       │ │ ▶ 1 みなさん、□□ □□□□□ございます。 │ │
│ │ [▶][⏮][⏭][はじめから]       │ │   2 □□は、□□の □□の …            │ │
│ │ ゆっくり｜すこし ゆっくり｜ふつう │ │   3 □つ□は、あいさつです。 ✨       │ │
│ │ [ 聞こえた 言葉 ______ ][入れる] │ │   …（中で スクロール。読んでいる文に ▶）│ │
│ │ キーワード！ +5「時間」        │ │                                  │ │
│ │ ひらいた 42% ▓▓▓▓▓░░｜のこり 6こ │ │                                  │ │
│ │ [ヒント]   [こたえあわせに すすむ] │ │                                  │ │
│ └──────────────────────────────┘ └──────────────────────────────────┘ │
└────────────────────────────────────────────────────────────────────────┘
```

- 左のカード（幅 44% くらい）= **メモ**。見出し・再生のボタン・速さ・入れる所・結果のバッジ（academy の言葉: キーワード！／よみで せいかい／を ふくむ！／おしい！／本文に ある／みじかいよ／もう 見つけたよ／とちゅうまで 合ってる／ローマ字みたい／本文に 出てこない）・
  進みぐあいの棒（`revealGoal` の所に 旗）・キーワードの残り・「見つけた: …」・ヒント・「こたえあわせに すすむ」。
- 右のカード（幅 54% くらい）= **ノート（台本）**。全部の文を虫食いで出す。開いた字は こげ茶。言葉が丸ごと開いたら ふりがなを付ける。
  読んでいる文は うすい緑の地にする。文を押すと その文を聞き直す。
- **浮かび上がる**: 当たると、(1) 入れた言葉の札が メモから上へ ふわっと のぼって消える、(2) ノートの その字が 金色に光ってから こげ茶になる、
  (3) 3D の大きな画面に その文が出ているときは、画面の字も 下から 浮かび上がって光る（0.8秒）。音は `ok`。はずれは 入れる所が ゆれる（ブザーは鳴らさない）。
- 3D の大きな画面（会場の「入社式」の画面を、リスニングの間だけ切りかえる）: いま読んでいる文を 大きく（虫食い）。文字は `text-canvas` で描く（ふりがなは データから）。
  こたえあわせの間は、見ている文を全部 開いて出す。リスニングが終わったら「入社式」にもどす。
- 話している人（ヘンディさん）は、声が鳴っている間「話す動き」にする。
- 進むのに要る情報（いまの文）は 3D の中にも出ている（必ず守るルール10）。入れる所は HTML（VR では、あとで 声の入力に置きかえる）。

画面の順番（1つのパネルの中で進む）:

1. **はじめ**: 題・「👂 ここに 注目して 聞きます」（`focus`）・「声を 聞いて、聞こえた 言葉を 入れます。ぜんぶ わからなくても 大丈夫です。わかった 言葉から 入れましょう。」・「▶ はじめる」（押してから 声が出る）。
2. **聞く**（上のレイアウト）。
3. **こたえあわせ**: 1文ずつ（← まえ／つぎ →）。その文の ▶・キーワードの英語（`glossary`）。最後の文まで見たら「つぎへ」。「もう いちど 聞く」で 2 にもどれる。
4. **意味のワーク**（下の 4.）。
5. おわり: メモに足して（`memo`）、パネルを閉じる。

入れた言葉は端末に保存し、途中でやめても つづきから できる（academy と同じ。開いた場所ではなく、入れた言葉を保存する）。

## 4. 意味のワーク（文の意味が分かったかを、楽しく確かめる）

聞いて開いた言葉を、すぐ「使う」。3つを続けて行う（どれも1分くらい）。読む・聞く確認なので、えらぶ形でよい（必ず守るルール3）。

1. **ことばと 絵を 合わせよう**（`kind: "match"`）: 絵のカード3まいと、言葉の札3つ（あいさつ・時間・相談）。言葉を押してから 絵を押す。
   合うと、絵の下に 言葉と英語（greeting など）が出て、ヘンディさんの その文が もう一度 流れる。ちがうときは「不正解。もう 一度 えらびましょう。」（札が ゆれる）。
2. **こんな とき、どうする？**（`kind: "situation"`）: 絵＋場面の文1つ＋行動2つ（大きなボタン）。4問。
   正解 →「正解！ 1つ目の『あいさつ』ですね。」。不正解 →「不正解。ヘンディさんの お話を もう 一度 聞いて、えらびましょう。」と出し、
   その場面の文（`line`）を もう一度 流してから えらび直す（まちがい → もう一度 聞く、が自然につながる）。
   まちがいの例は「あなた」の行動として書く（名前のある登場人物に させない。必ず守るルール8）。
3. **声で 言う**（ワークのあと、台本の `panel: talk`）: ヘンディさんが「大切な ことは 何でしたか。1つ 教えて ください。」と聞く。
   マイクで「あいさつです。」などと答える（話す練習は えらぶ形にしない）。あいさつ・時間・相談の どれかが聞きとれれば合格。
   このために、`content/talks.json` の `answer` の形に、`check`・`need`・`retry`（あれば、言葉が入っているかを見る）を足す。

おわったら、メモ「ヘンディさんの お話」（大切な こと 3つ）が自動で足される。

ステージ2のリスニングでは、ワークに `kind: "sort"`（聞いた事実の札を、ホワイトボードの「どこ？」「何人？」などの所に置く）を使う（`content/listenings/aoba-kickoff.json`）。この3つ（match・situation・sort）を部品として作る。

## 5. データ（`content/listenings/<id>.json`。1つのリスニングに 1ファイル）

`src/content/schema.ts` に `listeningFile` を足し、`npm run lint:content` で形と ふりがなを見る。フォルダの中の全部を読む（`import.meta.glob`）。

| 項目                   | 中身                                                                                                                       |
| ---------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `id`・`title`・`focus` | 題と、聞く前に伝える「ここに注目」                                                                                         |
| `participants[]`       | `{ id, name?, voice? }`。話す人。`name` が無いときは `speaker.<id>` の言葉を使う。ステージ2は ヘンディさんと 山本社長の2人 |
| `script[]`             | `{ speaker, text }`。1こまに1文（30字まで・分かち書き）                                                                    |
| `keywords[]`           | 点の高い言葉。台本に その字のまま 出ていること（チェックで止める）                                                         |
| `preOpen[]`            | はじめから開けておく言葉（虫食いにする）                                                                                   |
| `sounds[]`             | `[字, 読み]`。数字・英字の、聞くとき だけの読み（3つ = みっつ、5分前 = ごふんまえ、IT = あいてぃー）。台本に出ていること   |
| `revealGoal`・`check`  | 進める割合（%）、`{ minLength, maxMiss }`                                                                                  |
| `glossary[]`           | `{ word, en }`。N5 を超える言葉の英語（こたえあわせ・ワークで出す）                                                        |
| `works[]`              | `match`・`situation`・`sort`（上の 4.）                                                                                    |
| `memo`                 | `{ id, title, text }`。おわったら自動のメモに足す                                                                          |

絵の場所（`image`）は `public` からの道。絵が まだ無いときは、ネクマックスの絵を出す（豆知識と同じ）。

## 6. ヘンディさんのお話（文は `content/listenings/hendy-speech.json`）

テーマ「日本の ITの 会社で 働く ために 大切な こと」。大切なことは3つ: **あいさつ・時間・相談**。
ステージ1で体験したこと（元気に あいさつ・時間どおりに 会社へ・着いたら連絡）と、これから学ぶ 報告・連絡・相談に つながる。
ヘンディさんは「わたしも 外国から 来ました。はじめは、日本語が あまり わかりませんでした。でも、毎日 少しずつ 上手に なりました。」と話す
（成長の話。失敗の役ではない。academy の人物の設定と同じ）。

### 入社式の場面（s15-hall）の台本の変え方

席に座って、豆知識「前の 席に 座る」のあと:

| だれ                                         | 文                                                                                                                                                                                                                                                                                                          |
| -------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ヘンディさん                                 | みなさん、おはようございます。                                                                                                                                                                                                                                                                              |
| ヘンディさん                                 | ネクストメイクへ ようこそ。                                                                                                                                                                                                                                                                                 |
| ヘンディさん                                 | これから、大切な お話を します。                                                                                                                                                                                                                                                                            |
| ヘンディさん                                 | 聞こえた 言葉を、メモして ください。                                                                                                                                                                                                                                                                        |
| （豆知識 `memo-wo-toru`）                    | 題「メモを 取る」。文「日本の 会社では、話を 聞く とき、メモを 取ります。」もっと「聞こえた 言葉だけで 大丈夫です。あとで 見て、思い出せます。」英語 "In Japanese companies, people take notes while listening. Just the words you catch are enough."。絵 = メモしている絵（`/img/tips/memo-wo-toru.webp`） |
| ネクマックス（guide）                        | ヘンディさんの 声を 聞いて、聞こえた 言葉を 入れましょう。                                                                                                                                                                                                                                                  |
| （`panel: listening`・`mode: hendy-speech`） | 聞く → こたえあわせ → 意味のワーク2つ                                                                                                                                                                                                                                                                       |
| （`panel: talk`・`mode: speech-check`）      | ヘンディさん「%nickname%さん、1つ 聞いても いいですか。」「大切な ことは 何でしたか。1つ 教えて ください。」ヒント「あいさつです。」やり直し「もう 一度 言って みましょう。『あいさつ』『時間』『相談』の 中から 1つです。」しめくくり「そうです。よく 聞いて いましたね。」                                |
| ヘンディさん                                 | 今後の ことに ついては、%teacher%先生から お話が あります。                                                                                                                                                                                                                                                 |
| （このあとは今と同じ）                       | やることの「入社式に 出る」に線 → 「ステージ1 クリアです！」→ 修了証                                                                                                                                                                                                                                        |

今の「入社、おめでとうございます。」「わたしも 外国から 来て…」「わからない ことが あったら…」の3つのセリフは、お話の中に入ったので消す。
修了証の「きょうの ことば」に「相談（ask for advice）」「連絡（contact）」を足す。

### 絵

- メモしている絵（豆知識）と、ワークの絵4まい（あいさつ・時間・連絡・相談 = `public/img/listening/*.webp`）は、まず 3D の部品を撮って作る（`npm run shots` の仕組み。ちびキャラに ノートとペンを持たせる）。
- Codex で作る きれいな絵の頼み方は `docs/codex/stage2_visuals.md`。届いたら 置きかえる（ファイルの名前は同じ）。

## 7. 確かめ方

- 単体テスト: 判定（academy のテストを移す。かな・漢字・数字の読み・くり返し・ローマ字・とちゅうまで）、`preOpen`、台本のチェック。
- 最初から最後まで通すテスト（`e2e/stage1.spec.ts`）: 豆知識 → はじめる → 言葉を入れる（はずれ1回・読みで当てる・漢字で当てる）→ 進める割合 → こたえあわせ → ワーク（わざと1回まちがえる）→ 声で言う（にせの相手）→ 修了証。画面の写真を残す。
- 画面の写真で、虫食い・浮かび上がり・3D の画面の文字・どう森ふうのカードを見る。
