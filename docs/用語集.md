# 用語集（tomy さんに伝わる言い方）

academy（tomy1031/nexmax-academy）の `docs/用語集.md` と同じ考え方で使う。

- tomy さんに向けて書く文（チャットの返事・報告・質問、PR の題名、コミットの件名、ルールの文）では、下の「これからの言い方」を使う。
- 表に無い言葉でも、tomy さんの発言に出てこない言い方を新しく作らない。迷ったら tomy さんがその物を何と呼んでいるかを先に確かめる。
- 学生向けの「単語の間にスペースを入れる書き方」は学生向けの文だけで使う。tomy さんに向けた文では使わない。

## 報告の書き方（academy 2026-10-11 に決めたもの）

1. 最初の1〜2文で「何がどうなったか」を書く。見出しや絵文字のラベルは付けない。
2. 次に、どうやって確かめたかを短く書く。変えたファイルの名前は並べない。
3. tomy さんにお願いしたいことは、最後に1か所だけ書く。なければ「お願いすることはありません」と書く。A/B で選んでほしいときも、ここに入れる。
4. 確かめてほしいときは、開く URL・押す所・どうなっていればよいか、の3つを書く。
5. 技術的な選び方は聞かずに AI が決め、決めたことを一言だけ伝える。聞くのは、教材の中身や好みなど、tomy さんにしか決められないことだけ。
6. ファイル名・プログラムの名前は使わない。どうしても使うときは（ ）で何のことかを添える。単語の間にスペースを入れない。
7. 「結果」「範囲」「洗い出し」のような言葉だけで終わらせず、「何の結果か」「何の洗い出しか」を必ず書く。
