# 注意事項（tomy さんの指示と好み）

すべての作業の前に読む。tomy さんが言った指示や好みは、その場でここに書き足す（日付と元の発言つき）。
academy（tomy1031/nexmax-academy）の注意事項から、このアプリにも効くものを持ち越した（「academy から」と書いた行）。
持ち越さなかったもの（Cloudflare の本番の出し方・授業の曜日・Worker の大きさ・まなびマップなど academy の画面だけの話）は、
academy の `docs/constraints.md` を見る。

- 「設計時はFable5.2と相談してもOKです。グラフィック工場のアイデアやアバターについても何かアドバイスあれば聞いてもいいです」
- 企画メモ（`docs/企画メモ/2026-11-21_企画メモ.txt`）の要点:

  - 補足が要る所は、絵の入った「豆知識」を出す。
  - NMChat・路線図はメニューからいつでも見られるようにする。
  - キャラクターメイキングは r3f-ultimate-character-configurator を参考に。服にスーツが無いので、男女それぞれのスーツを作る。

## 2026-11-23 家・操作・信号・メモ

- 「デフォルトは寝巻きにしてください。」→ 服に「寝巻き」を足し、はじめの服にした。朝は寝巻きで起き（台本の `wear`）、着がえで スーツにする。

- 「家の中をもっとソファ、テレビがあったり、簡易キッチンがあったり、風呂やトイレ、玄関があったり、生活感のあるように」→ 1K の部屋にした
  （部屋: ベッド・つくえ・ソファ・テレビ・クローゼット／ろうか: 冷蔵庫・電子レンジ・キッチン・せんたく機／おふろ・トイレ・玄関）。
  カメラは 手前の上から ななめに見下ろす（向きは かえない）。手前と 部屋の あいだの かべは ひくくして、中が見えるようにした。
- 「カメラの視点のせいか、操作がしにくい」「十字キーの動きが外に出たら逆になる」→ 外で 十字キーの向きが 逆になっていたのを直した。町のカメラを 少し高く・はなした。
- 「ベッドや目覚ましなどに歩くと体が減り込む」→ 家具に 入れない四角（blocks）を付け、クリックで歩くときは 家具を よけて歩く（findPath）。
- 「外の人がガードレールに減り込みながら歩いている」→ 歩く人の道を ガードレールの内がわにした。
- 「信号の「おまちください」が光った時は押してくださいを消してください。」→ そのとおりにした。
- 「矢印が表示されている時に、左折の車が何台か動いているのを見せてください」「矢印と車の向きが合ってないです。左にして、手前側から左折する車を写して」
  → 車の信号の矢印を 左（←）にし、手前から来る車が 3台 つづけて左に曲がる。アップのカメラで 信号と 曲がる車を いっしょに見せる。
  左に曲がる車は 横断歩道の手前で曲がるので、歩く人の道を通らない。
- 「基本マウスクリックだけでなく、十字キーでもプレイできるようにして欲しい。階段やドアをオーバーしたら画面を次に切り替えるようにして欲しい。」
  → 十字キーで、いま押してほしい物（ドア・階段・券売機など）の前に入ったら、押したことにする。近くの物は Enter・スペースでも押せる。

  企画メモの「何線？メモを促す」は、この指示で 自動のメモに置きかえた。

## 学生向けの日本語（academy から）

- 学生が読む文は N4 学習中のレベルにそろえる。文法は N4 まで、1文は 30字（分かち書きの空白こみ）まで。
  ビジネス・IT の言葉は残す（ひらがなに開かず、漢字＋ふりがな＋英語で支える）（academy 2026-08-25）。
- **実際には N4 にとどかない学生が多い。** 文章では理解できない人がいる前提で作る。場面・気持ち・手順はまず絵（このアプリでは 3D の場面と動き）で伝え、
  文は添え物にする。1画面に長い文を並べない（1画面1文・1コマ1情報）（academy 2026-08-30）。
- 漢字には全部ふりがなを付ける。難しい語をひらがなにしない（「ひらがなだけでわかりやすくなることは、決してありません」academy 2026-07-28）。
  N5 を超える語は英語で意味を添える。ビジネス・IT の漢字語の後ろに（English）で添える。カタカナ語には付けない（academy 2026-10-22）。
- 学生向けの文は文節の間に半角スペースを入れる（分かち書き）。助詞は前の言葉に付ける。分かち書きにするとき助詞を足さない。
- 画面の言葉も同じ。読みにくいからとひらがなに開かない（けす→消す・ひらきます→開きます）（academy 2026-08-21）。
- 色の付いた面（濃い地に白い文字）では、ふりがなも白にする。文字の色とふりがなの色をいつも2つセットで決める（academy 2026-08-18・09-21）。
- 頭に「？」を浮かべさせるものを画面に置かない。見出し・ボタン・記号は、その場で意味が分かるものだけにする（academy 2026-09-10）。
- 大きな数は「万」を使わず桁区切りで書く（15,000円）（academy 2026-08-17）。
- 数を宣言しない（「大事なことは3つ」のような言い方をしない）（academy 2026-08-17）。
- 判定ははっきり書く。「よくできたね」のようなきれいごとだけで判定をぼかさない。判定のあとに次の行動を1つ添える（academy 2026-09-03）。
- 「タイ」という国名を使わない。それ以外の国名は自由に書いてよい（academy 2026-08-23）。
- 学生の名前はカタカナで持つ。名前の見本はカンボジアの名前にする（ソク・ソピア・ピアなど）（academy 2026-08-11）。
- 前の画面へ戻る道を、どの画面にも置く。行き止まりを作らない（academy 2026-08-21）。

## 絵（academy から）

- キャラクターの絵を手描きの SVG で作らない。ネクマックスは Codex の image-gen-2 で、基準の絵を参照に入れて作る。
- 説明のための絵は「雰囲気」で済ませない。絵だけで役割が読めるように作る（academy 2026-09-03）。
- 絵の中の人の表情は大げさにする（academy 2026-10-27）。
- 絵の縦横比は元のまま出す。切って人の顔を消さない（academy 2026-08-30）。
- 重要な日本語は絵に焼かず、文字のデータとして置く（ふりがな・読み上げが効かないため。academy 01ガイド）。

- r3f-ultimate-character-configurator（wass08）のモデルにはライセンスの記載が無い。作者の講座の利用規約（Caustic Lab LLC）は
